# Qnity Intern — Corporate Project 2026

Qnity Intern 團隊為公司策劃的 Corporate Project 成果展示網站，以花藝為主題，記錄活動內容設計、活動花絮照片，以及為公司設計的感謝卡片。

## 網站內容
- **活動主題** — 本次企業關懷活動的發想與主題說明
- **活動內容設計** — 從企劃、花材選配到執行的完整流程
- **花藝相冊** — 活動現場與作品照片
- **感謝卡片** — 為主管與同仁設計的感謝卡內容
- **實習生團隊** — 團隊成員介紹

## 技術架構
純靜態網站，不需要任何建置工具：
- `index.html` — 網站內容
- `css/style.css` — 樣式
- `js/main.js` — 燈箱效果、滾動動畫、導覽列高亮
- `images/` — 活動照片

## 本機預覽
直接用瀏覽器開啟 `index.html` 即可，或使用 VS Code 的 Live Server 擴充套件。
